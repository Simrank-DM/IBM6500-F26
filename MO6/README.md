Simran Kaur's AO2 proposal presentation for the TBFI CEP project.

## Render

Install Quarto and R. In R, install the required package once:

```r
install.packages("knitr")
```

From this folder:

```bash
quarto render Simran-Kaur-M06-CEP-Presentation.qmd
```
